# Java Contact Management System

A simple console-based Contact Management System built using Java. This project allows users to store and manage contact details by adding, viewing, searching, and deleting contacts.

## Features

* Add new contacts
* View all contacts
* Search contacts by name
* Delete contacts
* Menu-driven console interface

## Technologies Used

* Java
* ArrayList
* Scanner Class
* Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Java-Contact-Management-System.git
```

2. Compile the program:

```bash
javac ContactManagementSystem.java
```

3. Run the application:

```bash
java ContactManagementSystem
```
